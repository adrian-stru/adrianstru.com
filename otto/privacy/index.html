Otto privacy policy

Last updated: October 16, 2026

Otto is a private assistant with a single user, its owner Adrian Stru. This policy explains how Otto handles the Google user data it accesses.

What Otto accesses

With the owner's permission, Otto has read-only access to the owner's Gmail (gmail.readonly). It searches for and reads purchase receipts and order confirmations. It cannot send, delete or change email.

How the data is used

Otto uses receipt details (merchant, date, amount, items, order number) to match purchases to transactions in the owner's own budgeting system, and to attach a copy of the receipt there. It uses email for no other purpose.

Where it is processed and stored

Otto runs on a computer the owner controls. Matched receipt details and copies are stored in the owner's self-hosted budgeting system. To read a receipt, Otto may send relevant parts of the email to an AI model provider the owner uses (OpenAI or Anthropic), under that provider's terms. That data is used only to answer that request.

Sharing

Otto does not sell Google user data, share it with anyone else, or use it for advertising. No human other than the owner reads it.

Limited Use

Otto's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Otto keeps only what it needs to remember which receipts it has already matched. The owner can delete stored receipt copies in the budgeting system at any time. Access can be revoked at any time at myaccount.google.com/permissions. Otto then stops reading Gmail.
